# GST Filing Deadlines (India)

## GSTR-1
- Outward supplies return (B2B, B2C, credit/debit notes, exports).
- Typical due date: **11th of the following month** (confirm against current GST calendar / notifications).
- Quarterly filers (QRMP) follow quarterly GSTR-1 / IFF rules.

## GSTR-3B
- Summary return and tax payment.
- Typical due date: **20th of the following month** for monthly filers.
- Must reconcile with books and GSTR-1 data before filing.

## Data readiness for GSTR-1
Required per invoice (as applicable):
- Counterparty GSTIN/UIN (B2B)
- Trade / party name
- Invoice number and date
- Invoice value and taxable value
- GST rate / tax breakup
- Place of supply
- RCM flag
- Invoice type (Regular / SEZ / Export)
- E-commerce GSTIN when sold via e-commerce operator

## Penalties (high level)
- Late fee and interest may apply for delayed GSTR-1 / GSTR-3B.
- Always verify current rates on the GST portal before advising clients.
